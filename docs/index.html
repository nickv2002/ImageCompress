Smaller images.
Same pictures.

ImageCompress shrinks PNG, JPEG, WebP, GIF, AVIF, JPEG XL and HEIC files, or converts between them, from a native Mac app, a right-click in Finder, or the command line.

Download for Mac Homebrew and Linux

Free and open source · Mac app: macOS 15 or later, Apple silicon and Intel · Command line: macOS and Linux (x86_64, ARM64)

Pick a format and a quality. That's it.

Two controls in the toolbar cover almost everything: keep each file's format or convert to a modern one, and choose how much you are willing to change.

QualityWhat it means
LosslessEvery pixel stays exactly the same. Smallest safe savings.
Visually losslessTechnically lossy, but you would not see a difference. JPEG, WebP, AVIF and JPEG XL files are measured with SSIMULACRA2, a perceptual metric, and each gets the lowest quality setting that still looks the same.
SmallerA little loss that is hard to spot, for a big size reduction.

Formats: preserve the original, or convert to JPEG XL, AVIF, HEIC, WebP, JPEG or PNG. Which one should I use?

Make your own presets

Twenty-one presets are built in, one for every format and quality. When you want something else, save the exact settings you use as your own preset and run it with one click.

Any combination

A preset can hold any option: format, quality or a target score, a maximum size in pixels, what metadata to keep, where the results go, and every encoder setting.

{% include pills.html on="both" %}

Everywhere you work

Star a preset to put it in the toolbar, show it in the Finder right-click menu, or run it with imgcompress run --preset.

Easy to share

Each preset is a small JSON file. Edit it by hand, send it to a colleague, or keep it next to a project's build scripts.

Undo

The app keeps replaced originals for 24 hours, so one click puts a file back. On the command line, --backup-dir keeps them and imgcompress undo restores them. Undo refuses if the file changed since. How undo works

{% include pills.html on="both" %}

Never bigger

A result is only kept when it is smaller than the original. Files are replaced atomically, and existing files are never overwritten unless you ask.

{% include pills.html on="both" %}

Smaller JPEGs than mozjpeg

JPEGs are made with Google's jpegli by default. At the same visual quality its files came out 4–13% smaller than mozjpeg's in our tests, and they open everywhere a JPEG does. JPEG encoders

Keep the colour profile, keep everything, or keep EXIF without GPS location. Dates are preserved.

Everything built in

Every encoder is part of the app: jpegli (the default for JPEG), mozjpeg, oxipng, libimagequant, libjxl, libavif, libwebp and gifsicle. No Homebrew or Python needed.

The same engine on the command line

imgcompress runs on macOS and Linux, shares presets with the app, and is safe to re-run.

# Compress every image under a folder, in place
imgcompress run ~/Pictures

# Convert to AVIF with a preset, keeping the originals next to the results
imgcompress run --preset avif-visually-lossless --destination alongside photos/

# Use a preset file someone sent you
imgcompress run --preset ~/Downloads/web-thumbnails.json site/images/

Free and open source

Install

The Mac app updates itself. Homebrew, apt and dnf keep the command line tool current.

Mac app

Includes the imgcompress command.

brew tap nickv2002/tap
brew trust --cask nickv2002/tap/imagecompress
brew install --cask imagecompress

Or download the app and move it to Applications.

Debian, Ubuntu

Static build, no dependencies.

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/nickv2002.asc \
  https://nickv2002.github.io/packages/nickv2002.asc
echo "deb [signed-by=/etc/apt/keyrings/nickv2002.asc] \
https://nickv2002.github.io/packages/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/nickv2002.list
sudo apt update && sudo apt install imgcompress

Fedora, RHEL, openSUSE

Static build, no dependencies.

sudo curl -fsSLo /etc/yum.repos.d/nickv2002.repo \
  https://nickv2002.github.io/packages/rpm/nickv2002.repo
sudo dnf install imgcompress

openSUSE: sudo zypper addrepo the same .repo URL. More on the repository.

Command line only

macOS or Linux, with Homebrew.

brew tap nickv2002/tap
brew trust --formula nickv2002/tap/imgcompress
brew install imgcompress

Tarballs for every platform are on the releases page.
